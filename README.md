
# AI-Exercise-Counter-and-Feedback
Using open cv to track movement we use the joint points to calculate angles such that we can count the reps of the exercices.

Instalation and utilization guide guide:

-press button "<>CODE" from witch you copy the url from htpps

-inside git bash go to the place you want to save the project and paste the command:git clone https://github.com/Andrei-Patrasca/AI-Exercise-Counter-and-Feedback.git

-open the project in PyCharm 

-run the file MergedApp.py

-click the biceps curls button to start

-make sure your left hand is vizible to the camera
